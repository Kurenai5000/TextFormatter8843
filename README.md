# TextFormatter8843
Formats spaces in text. Goes well with my translator tool if the translator gives you text blocks.

1.Run by opening the "main.html" file to open the webUI in your browser.

2.Input your deepseek API key in the "Input your API key" section.

3.Click "Choose File" to input a .txt file to translate.

4.Click the "Start Formatting" button.

5.Once completed, click the "Download Translation" button.
